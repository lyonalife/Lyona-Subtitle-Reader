# Системные требования

- Windows 10/11 x64, Windows PowerShell 5.1.
- NVIDIA с compute capability 7.5 или выше и совместимым драйвером CUDA 12.
- Видеопамять: желательно от 12 ГБ, предпочтительно 16 ГБ. На 8 ГБ работа возможна, но при нагрузке игры возможны задержки и сбои.
- Оперативная память: желательно 32 ГБ.
- Процессор x64 с AVX2, FMA, F16C и BMI2 для нативного движка.
- Свободное место: ориентировочно от 5 ГБ для программы, моделей и временных файлов.
- Русский компонент Windows OCR (`Language.OCR~~~ru-RU`) либо отдельно установленный Tesseract с `rus.traineddata`.
- OBS Studio 28+ только для режима OBS WebSocket.
- Для карты захвата нужен совместимый драйвер DirectShow или Media Foundation.

Интернет необходим для первоначальной загрузки моделей, если они ещё не скачаны. Генерация речи выполняется локально. CPU-режим предусмотрен, но может быть слишком медленным для игры в реальном времени. Точный минимум оборудования не установлен.
