# Ограничения бета-версии

- Возможны задержки, пропуски фраз, ошибки распознавания, ударений и интонации.
- Производительность зависит от оборудования и нагрузки игры. Стабильная работа на всех ПК не гарантируется.
- В меню текущего релиза доступен мужской голос.
- При резервном видимом захвате перекрытые или свёрнутые окна могут распознаваться неправильно.
- Некоторые карты захвата не могут одновременно использоваться несколькими приложениями. Защищённый HDCP сигнал не распознаётся.
- Рамка Windows Graphics Capture может оставаться видимой в зависимости от разрешений Windows.
- Выделяйте только область субтитров для повышения качества OCR.
- Программа озвучивает русские субтитры, а не переводит иностранную речь.
