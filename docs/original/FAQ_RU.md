# Частые вопросы

**OBS не подключается.** Проверьте запуск OBS, сервер WebSocket, адрес `127.0.0.1`, порт и пароль.

**Русские субтитры не распознаются.** Установите русский компонент Windows OCR или используйте отдельно установленный Tesseract с русским языком.

**Карта захвата не работает.** Проверьте драйвер, сигнал, поддерживаемый формат и не занято ли устройство другой программой.

**Не найдены модели Qwen.** Через «Проверить / загрузить Qwen» скачайте или выберите `qwen-talker-1.7b-base-Q8_0.gguf` и `qwen-tokenizer-12hz-Q8_0.gguf`. При прерванной загрузке повторите попытку.

**Нет звука.** Проверьте громкость Qwen, выбранные наушники или динамики и кнопку «Послушать». Проверьте микшер Windows и маршрут виртуального аудиоустройства. Для диагностики можно использовать `CheckQwenSound.cmd` из сборки.

**CUDA не запускается.** Проверьте драйвер NVIDIA. Программа предусматривает переход на CPU; при наличии кнопки «Повторить CUDA» можно повторить попытку. Для диагностики используйте `CheckQwenNative.cmd`.

**Озвучка отстаёт или пропускает фразы.** Это возможно при высокой нагрузке игры, недостатке видеопамяти или работе на CPU. Точная причина зависит от конкретной конфигурации.

Не публикуйте свои настройки, пароли и журналы без проверки на личные данные.
