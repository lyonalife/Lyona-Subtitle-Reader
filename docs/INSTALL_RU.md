# Установка и запуск

1. Скачайте ZIP программы из раздела Releases.
2. Полностью распакуйте архив в отдельную папку.
3. Запустите `LyonaSubtitleReader_Streamer.exe`. Устанавливать Python не нужно.
4. Нажмите «Проверить / загрузить Qwen» и загрузите модели или выберите уже скачанные GGUF. Модели хранятся в `%LOCALAPPDATA%\LyonaSubtitleReader\models`.
5. Выберите источник изображения и выделите область русских субтитров.
6. Выберите Windows OCR (требуется русский компонент распознавания Windows) или дополнительный Tesseract с русским языком.
7. Выберите аудиоустройство, нажмите «Послушать», затем «Начать озвучку».

## Источники изображения

- Экран или окно Windows: используется Windows Graphics Capture, при недоступности — резервный видимый захват.
- Карта захвата: выберите устройство и поддерживаемые разрешение, FPS и пропорции сигнала.
- OBS: включите сервер WebSocket, укажите порт и пароль при необходимости, обновите список источников. Для остальных режимов OBS не нужен.
- Телефон: требуется доступная Windows камера или HTTP/HTTPS/RTSP видеопоток. Кабель для зарядки сам по себе не передаёт изображение.

Для стрима добавьте звук программы через захват аудио приложения в OBS.
