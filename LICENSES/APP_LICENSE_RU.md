# Лицензия Streamer

Исходный код Streamer распространяется на условиях GPL-3.0-only (текст в `../LICENSE`). Это соответствует использованию `obsws-python` с лицензией GPL-3.0-only. Исходный код и сценарий сборки включены в ZIP.

Сторонние компоненты сохраняют собственные лицензии: в частности, NVIDIA CUDA DLL не становятся GPL, а распространяются по отдельной лицензии NVIDIA из этой папки. Qwen GGUF не включены в ZIP и загружаются только после согласия пользователя. Синтетические WAV-референсы описаны в `VOICE_PROVENANCE_RU.md`.
