# Lyona Subtitle Reader — Streamer

**Бесплатная программа для озвучки игровых субтитров в реальном времени.**

Lyona Subtitle Reader распознаёт русские субтитры на экране и озвучивает их с помощью нейросети Qwen3-TTS. Программа создавалась для игр, в которых есть русские субтитры, но отсутствует русская озвучка.

Подходит как для стримеров, так и для обычных игроков.

## ✨ Возможности

- Автоматическое распознавание и озвучка субтитров.
- Мужской голос на основе Qwen3-TTS 1.7B.
- Локальная генерация речи без платных подписок и API.
- Захват экрана и отдельных окон.
- Поддержка совместимых карт видеозахвата.
- Возможность использования с консольными играми.
- Подключение к OBS через WebSocket.
- Работа без OBS.
- Выбор устройства вывода звука.
- Поддержка NVIDIA CUDA и CPU.
- Настройка скорости озвучки.

## 📥 Скачать программу

Готовая версия программы доступна в разделе **Releases** этого репозитория.

1. Скачайте ZIP-архив.
2. Полностью распакуйте его в отдельную папку.
3. Запустите `LyonaSubtitleReader_Streamer.exe`.
4. При необходимости загрузите модели через программу.
5. Выберите источник изображения и область расположения субтитров.
6. Выберите устройство вывода звука и запустите распознавание.

Устанавливать Python отдельно не требуется.

[Подробная инструкция по установке](docs/INSTALL_RU.md)

## 💻 Системные требования

| Компонент | Рекомендации |
|---|---|
| Операционная система | Windows 10 / 11, 64-bit |
| Видеокарта | NVIDIA с поддержкой CUDA |
| Видеопамять | Желательно от 12 ГБ, предпочтительно 16 ГБ |
| Оперативная память | Желательно 32 ГБ |
| Интернет | Для первоначальной загрузки моделей |

Программа может работать на видеокартах с 8 ГБ видеопамяти, однако при одновременном запуске требовательных игр возможны задержки и нестабильная генерация речи.

Также предусмотрена работа на CPU, но скорость озвучки может быть значительно ниже.

Рекомендации по оборудованию являются ориентировочными.

## 🎮 Использование с OBS

Программа поддерживает подключение через OBS WebSocket, что позволяет распознавать субтитры из источников OBS.

Звук озвучки можно добавить в OBS через захват аудио приложения.

Для обычной игры установка OBS не обязательна.

## ⚠️ Особенности бета-версии

Это первая публичная бета-версия программы.

- Возможны задержки озвучки и пропуски отдельных фраз.
- Иногда встречаются неправильные ударения и интонации.
- Качество распознавания зависит от шрифта, размера и расположения субтитров.
- Скорость генерации зависит от оборудования и текущей нагрузки компьютера.
- Стабильная работа на всех конфигурациях не гарантируется.

Программа озвучивает уже существующие русские субтитры, а не переводит иностранную речь.

## 🔒 Конфиденциальность

Распознавание субтитров и генерация речи выполняются локально на компьютере пользователя. Для основной работы программы не требуется отправлять игровые субтитры в облачные сервисы.
